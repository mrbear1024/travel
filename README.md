# AI 旅行规划师

智能旅行规划网站 — 输入你的旅行想法，AI 为你量身定制完美旅程。

## 功能

- **智能问卷** — AI 分析你的旅行想法，生成针对性问题收集详细需求
- **完整规划** — 自动生成包含行程、天气、美食、装备等全方位旅行计划
- **流式输出** — 实时展示 AI 生成内容，无需漫长等待
- **导出打印** — 一键打印或导出 PDF

## 计划内容包含

| 模块 | 内容 |
|------|------|
| 行程总览 | 每日概要表格 |
| 每日详细行程 | 交通、景点、美食、住宿推荐 |
| 天气穿衣建议 | 各地天气表格 + 穿搭推荐 |
| 美食攻略 | 必吃美食、推荐餐厅、特色小吃 |
| 玩乐攻略 | 必去景点、小众推荐、拍照点 |
| 行李清单 | 分类整理的完整装备清单 |
| 装备购买推荐 | 本次旅行建议购买的装备 |
| 预算估算 | 分项费用 + 三档预算 |
| 实用贴士 | 安全提醒、当地风俗、APP 推荐 |

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 配置 API Key

编辑 `.env` 文件，设置你的 Anthropic API Key：

```
ANTHROPIC_API_KEY=sk-ant-xxxxx
PORT=3000
```

### 3. 启动服务

```bash
npm start
```

访问 http://localhost:3000 开始使用。

## 技术栈

- **后端**: Node.js + Express
- **前端**: Vue 3 + Tailwind CSS + Marked.js（CDN 加载）
- **AI**: Claude API（Anthropic）
- **通信**: SSE（Server-Sent Events）流式传输
